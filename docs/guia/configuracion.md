# ⚙️ Configuración de MkDocs

El comportamiento y diseño del sitio se gestionan desde el archivo raíz `mkdocs.yml`.

## Personalización del Tema
El sitio utiliza el tema **Material for MkDocs** con las siguientes extensiones activas:
*   `navigation.tabs`: Navegación superior por pestañas.
*   `navigation.sections`: Agrupación visual en menús laterales.
*   `content.code.copy`: Botón rápido para copiar bloques de código.
